# scripts/

Lesson narration, rewritten and split into scenes for pasting into an AI
video tool (Google Vids or similar) — separate from `production/`, which is
this project's own Remotion-based render pipeline. The two are independent;
nothing here changes the videos already rendered from `production/`.

**Start here:** `ai-video-master-prompt.md` — voice and pacing notes, the
Arabic pronunciation reference, and what to do if a word ever comes out
wrong. Google Vids has no field to paste a prompt into, so the one fix
that actually mattered — the program's name getting spelled out "A-C-T"
— is written directly into the scripts themselves ("Act", not "ACT",
inside every spoken scene) rather than left to an instruction. Read the
master prompt once anyway, for the Arabic lines.

**Then:** `lesson-01.md` through `lesson-07.md` — Unit 1 (Self-Awareness,
lessons 1–5) and Unit 2 (Social Awareness, lessons 6–7), complete. Each
scene is capped at 800 characters so it pastes into one scene of your tool
directly. Each file also carries its own short list of things worth
knowing before you generate it — an unverified quotation, a link that
needs a live check, that kind of thing.

**Not started yet:** Units 3–4 (Lessons 8–20). The Trainer Manual's own
divider pages confirm the real shape of the rest of the course: Unit 3
(Social Problems) is lessons 8–12, five lessons; Unit 4 (Initiatives Based
on Skills) is lessons 13–20, with two pairs of lessons combined into single
sessions in the source (15+16, 17+18). None of Unit 3 or 4 has been
extracted from the manual yet — that's real new work, the same care Units
1 and 2 got. Building it is on hold until asked for.

**What changed from the original lesson scripts** (in `lessons/*/script/`):
every activity written for a live group is rewritten for someone watching
completely alone, and any mention of a classroom, a trainer, or points and
prizes is gone — the same house rule already applied to the finished
videos, extended here to a few spots that hadn't been touched yet. The
underlying facts and activities are unchanged from the source curriculum.
