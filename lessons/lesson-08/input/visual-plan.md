## Lesson-level visual direction

- Default presenter: `PresenterCornerRight`.
- Full-bleed Ali only for the opening question, one important reflection, and the close.
- Main visual idea: **move from a vague problem to a precise issue statement**.
- The five issue indicators should be drawn as one structured formula, not as a generic bullet list.
- The lion example is an external-video handoff, not embedded media.
- Avoid competition, voting, points, classroom teams, or workshop props.
- Keep the issue-research visuals practical and mature for ages 17–35.
